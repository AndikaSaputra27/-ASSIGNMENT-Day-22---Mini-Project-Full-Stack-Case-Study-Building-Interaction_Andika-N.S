# MyStore - Classic T-Shirt

Project toko online sederhana menggunakan HTML, CSS, dan JavaScript.

## Fitur

1. Menampilkan produk Classic T-Shirt.
2. Memilih warna produk.
3. Memilih ukuran S, M, L, XL, XXL, dan 3L.
4. Mengatur jumlah pembelian.
5. Menghitung subtotal otomatis.
6. Validasi jumlah pembelian berdasarkan stok.
7. Menambahkan produk ke keranjang.
8. Zoom gambar produk.
9. Form komplain produk.
10. Menyimpan komplain menggunakan localStorage.
11. Mengambil data produk dari API menggunakan fetch dan async/await.

## Cara Menjalankan

1. Buka folder project di Visual Studio Code.
2. Pastikan seluruh file berada pada struktur folder yang benar.
3. Install extension Live Server jika belum tersedia.
4. Klik kanan file index.html.
5. Pilih Open with Live Server.
6. Untuk halaman API, buka api.html.

## Penyimpanan Komplain

Data komplain disimpan di localStorage dengan key:

mystore-complaints

Data hanya tersimpan pada browser yang digunakan.

## API

Contoh endpoint:

https://dummyjson.com/products/1

Ganti endpoint sesuai API yang digunakan pada tugas sebelumnya.
