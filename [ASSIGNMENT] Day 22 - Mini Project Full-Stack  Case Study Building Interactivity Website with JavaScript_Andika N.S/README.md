# SimpleStore — Product Detail Assignment

Project ini menggunakan:

- HTML
- CSS
- Vanilla JavaScript
- Node.js
- Express
- DummyJSON API
- SQL SQLite

## Fitur

1. Product 1 menggunakan data hardcode.
2. Product 2 menggunakan data dari API.
3. Loading indicator.
4. Error handling dan tombol retry.
5. Validasi jumlah produk.
6. Kalkulasi subtotal otomatis.
7. Penyimpanan pesanan ke database SQLite.
8. Backend menggunakan Express.

## Persyaratan

- Node.js versi 18 atau lebih baru.
- npm.
- Visual Studio Code.

## Cara Menjalankan

Buka folder project di VS Code.

Buka terminal dan jalankan:

```bash
npm install
